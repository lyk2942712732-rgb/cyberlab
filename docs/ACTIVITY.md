# 学生实验操作记录

采集对象是操作结果：默认交互式 Bash 提交的完整命令、Firefox 网页完成的字段输入与提交、网页点击、页面导航、桌面点击及支持无障碍接口的控件最终文本。没有屏幕截图、视频、音频、逐键记录或鼠标移动轨迹。

## 数据含义

- `terminal.submit`：Bash 读完一条完整命令、准备执行时记录原始命令与当前目录；不是执行成功证明。保留多行、粘贴后的最终值、历史命令再次提交。不会把编辑中的文字写入日志。
- `web.change`：字段修改完成、离开字段或单行输入框回车时的最终值。同值的 change/focusout 通知去重。
- `web.submit`：提交时可编辑字段的值，表示提交尝试，不代表服务器接受。密码与验证码字段隐藏。
- `web.click`：网页元素名称、标签、标识和点击位置。
- `web.navigate`：实际页面导航及浏览器提供的转换类型；不宣称还原地址栏原始输入。
- `ui.click`：桌面窗口与点击位置；能读取无障碍接口时补充控件身份。未知目标明确标记 `coordinates_only`。
- `ui.change`：有无障碍可编辑文本接口的控件完成修改后的值。Firefox 网页字段由扩展负责，避免用桌面文本推测。

没有通用方法从任意软件中读取最终文本。未接入的 shell、终端内交互程序、无无障碍接口的自绘编辑器，不宣称具有最终文本覆盖。学生进程持有本会话日志目录，这是一份教学过程记录，不是防篡改审计证据。

## 存储和生命周期

每个 Kali 只挂载自身的 `/var/lib/cyberlab/activity/<session-id>`。重置创建新代次子目录，已有记录留在宿主机。靶机不挂载日志目录。每代次包含 `events.sqlite3` 和 `state.json`，不读取其他格式。

事件经 UID 校验的 Unix socket 送入单个写入器，SQLite 提交成功后才响应。事件 UUID 用于传输重试去重；两次实际操作拥有不同 UUID。单条消息上限 64 KiB、内容 16 KiB，日志默认 64 MiB；超限或写盘异常要暴露状态，不能无声丢弃或覆盖原记录。

写入器每两秒更新心跳；桌面观察器具备父进程死亡信号。运行监控与桌面健康分开。心跳过期、进程退出或收尾失败显示为中断，完整收尾需要写盘和数据库完整性检查。采集收尾失败不能阻止实验容器和网络回收。

一旦某个输入来源报告缺失，本代次始终保留“不完整”标记，恢复连接或关闭浏览器不会清除它。容量到达上限后停止写入，已确认落盘的操作仍可读取。

管理端“运行实例 → 操作记录”按实验代次查看、分页，每页至多 100 条。内容接口仅管理员可访问；学生资源面板只能看到状态与条数。

## 验证

后端：`cd backend && pytest && ruff check app tests`。

Linux 写入器测试：`python3 -m unittest discover -s docker/kali/activity -v`。

桌面集成脚本 `docker/kali/activity/verify_desktop.py` 必须显式运行在一次性测试容器中；它会打开终端和 Firefox、发送实际桌面输入，并断言最终内容、重复提交、草稿排除和密码隐藏。不得在学生正在操作的桌面执行。

部署验收还需记录 Kali 启动/桌面首帧时间、Firefox 操作期间 CPU/内存峰值、OOM 计数、长时间运行增长量及采集进程异常回收结果。验收实测结果另存部署记录，不能以配置上限代替实测。

`verify_native.py` 验证中文粘贴和命名控件点击；`verify_lifecycle.py` 会停止/杀死采集器并填满测试日志，**只用于一次性测试桌面**。`scripts/verify_activity_soak.py` 对带 `cyberlab.qa=activity` 标签的容器执行长时间终端与 Firefox 操作。`scripts/verify_vnc_bridge.py` 提供仅本机监听的 SSH/Docker exec 测试桥，配合 `frontend/e2e/desktop-performance.spec.ts` 测试真实画面；正式部署模式使用专用测试会话凭证文件，不经过此桥。
