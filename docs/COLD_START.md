环境：Windows 11 26200、i7-14650HX、16GB；VMware Workstation 16.2.4，日志 `Monitor Mode: ULM`；Ubuntu 4 vCPU / 4GB，Docker 29.7.2；测试 Kali CPU 上限 3、内存 1536MB。镜像已在本机，实验容器每次新建。

## 复测方法

以学生登录后发出创建实验 API 的时刻开始计时，每 3 秒查询 Session，直到 READY；此时验证 Kali 内可访问本次靶机，采集 agent 报告就绪。停止实验并等待 DESTROYED，确认容器和实验网络被回收后再测下一轮。保存每次 Session ID 和编排器分段日志。不能将重连已有桌面、复用容器或省略采集就绪计为冷启动。
